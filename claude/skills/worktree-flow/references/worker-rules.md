## どの worker にも渡す決まり（orca-launch が brief の先頭に足す）
- 操縦席（`.orca/` の cockpit.json など）を書かない
- sandbox で止まった操作は別の方法で通そうとせず、止まったコマンドと理由を報告に書く
- 今やれる作業は今やる（agents/common.md「判断」の「聞かずにやる」）。依頼の延長にあるものを「別 PR で」「次回」「範囲の外」と書いて残さず、済ませてから worker_done を送る
- 途中経過を coordinator（窓口か担当）に送らない。送るのは、完了（取り込める結果と commit の SHA）・停止・深田の判断の依頼・調整（ほかの作業とぶつかる、順番や範囲を変えてほしい、深田と話し中）の 4 つだけ
- 従量課金の LLM API（Bedrock・Anthropic の API キーなど）を呼ぶときは、回数・見込み額・コマンドを coordinator に送り、深田の許可を得てから実行する。検証は stub か記録済みの応答で行い、CI では呼ばない
